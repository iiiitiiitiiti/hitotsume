# 001. 新しいタブには拡張機能でなく Web アプリの URL を指定する

- 日付: 2026-10-19
- 対象: アプリ全体の構成

### 決定

Vivaldi の「新しいタブページ → 特定のページ」に GitHub Pages の URL を指定する。中身は gaman-log と同じ Vite + React + TypeScript + PWA にし、保存はその端末のブラウザだけにする。

### 背景

X を開く前に今やることを目に入れたい。有料の新しいタブ拡張は使わず、自作すると決めた（2026-10-19）。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 新しいタブを差し替える拡張機能 | Vivaldi は URL を指定できるので不要。配布と更新の手間だけ増える |
| ビルドなしの1枚の HTML | オフライン表示の仕組みとテストを手で書くことになり、既存アプリと作法が分かれる |
| 端末間で同期する | ログインと運用が増える。ユーザーが「この端末のブラウザだけ」を選んだ |
| Google Fonts を読み込む | 描画を止め、オフラインで欠ける。自前配信して precache に入れた |
| 新しい版が来たらすぐ再読み込み | 開いている全タブが一斉に再読み込みし、書きかけが消える。裏のタブで書きかけが無いときだけ切り替える |

### 影響範囲

- 保存キー `hitotsume:v1` の形を変えるときは `version` を上げ、読み替えを足す
- 新しいタブではアドレスバーにフォーカスが乗るため、キー操作は画面を一度クリックしてから効く。画面の折りたたみに案内を書いた

### 検証

- 内蔵ブラウザで、決める〜元に戻す・2タブの同期と衝突・暗い画面の再読み込み・幅375px を確認した（2026-10-19）
- 公開先で Service Worker が登録され、オフラインで表示されること。Vivaldi の新しいタブに設定して表示されること
