# 002. 新しいタブをダッシュボードにし、PC の中の情報は手元の係から取る

- 日付: 2026-11-06
- 対象: 画面全体・`helper/`

### 決定

画面は公開中の Pages アプリのまま「一日の軸」の形に作り替える。予定・Tech News・作問の種・note・Claude の使用量は、PC の起動時に動く Node の係（`127.0.0.1:47615`）から JSON で受け取る。天気・地名検索・Wikipedia はページから直接取る。

### 背景

ユーザーは Ctrl+T を使わず、ブックマークを新しいタブで開く。そのため今やることだけの新しいタブはほとんど目に入らなかった。出す場所を変える案は退けられ、「新しいタブのまま、載せる中身を増やす」と決まった（2026-11-06）。予定などを PC の外へ出さない条件で、手元の係を置くことにユーザーが同意した。見た目は3案（数字の表・一日の軸・色の面）から「一日の軸」が選ばれた。その前に、今やることを目立たせすぎる案と、同じ形の白いカードを並べた案は退けられている。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| B. 係がアプリ自体も配り、新しいタブを `http://127.0.0.1:47615` にする | origin が変わり、今の保存データが見えなくなる。係が止まると新しいタブが開かない。A が Vivaldi で通らなかったときの退避先として残す |
| 使用量を statusLine の控えから読む | デスクトップアプリでは状態行が動かず、控えが作られなかった（2026-11-06 に確認） |
| 使用量の欄をやめる | ユーザーが「PC のログインで直接聞く（非公式）」を選んだ |
| Cursor の使用量 | 会社のアカウントで、手元に記録が無く、ログインの鍵が要る |
| note の「おすすめ」 | ログインが要る。タグの RSS にした |

### 影響範囲

- 新しい保存キー `hitotsume:links`・`hitotsume:weather`・`hitotsume:noteTag`。今やることの `hitotsume:v1` は変えていない
- CSP の `connect-src` と `img-src` を広げた（DESIGN.md「更新・文字・テーマ」）
- 係は GitHub Pages に載らない。コードを直したら PC で `helper/start.ps1 -Restart` を実行する

### 検証

- `npm run lint`・`npm test`（48件）・`npm run build` が成功（2026-11-06）
- 係の5つの端点が `ok:true` を返し、Origin 無し・別 Origin・別 Host は 403
- 手元のプレビューで、軸・3つの箱・4つの読み物・ダーク・幅517px を目視。係を止めた状態では案内が上に1回だけ出て、「つなぎ直す」で戻る。決める→全部済んだ→元に戻すのあと、フォーカスが「一手済んだ」へ戻る
- 未確認: 公開ページから Vivaldi で係へつながるか（Local Network Access の許可）
